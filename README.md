# auxeticslab.com

Website of the Auxetics Lab at Griffith University: plain static HTML and one stylesheet, no build step.

## Publishing
The site is served by GitHub Pages from the `main` branch, on the custom domain in `CNAME` (`www.auxeticslab.com`).

- Make changes on a branch and open a pull request.
- Merging into `main` publishes the site automatically, usually within a minute.
- To preview locally, run `python3 -m http.server` in the repository folder and open http://localhost:8000.

## Website Content and Editing
### Home
- Large/Display text
- Image (preferably 16:9) + Image caption
- About Auxetics Lab
- Research Focus
- Another Paragraph (?)
- Our Team

### Research
- Large/Display text
- Overview
- Focus 1 (?)
- Focus 2 (?)
- Focus 3 (?)

### People
- Overview
- Founding team
  - Member picture
  - Member name
  - Member position
  - Member description
  - Link to website, email
- Researchers (or other member category)
  - Member picture
  - Member name
  - Member position
- Alumni
  - Member picture
  - Member name
  - Member position

### Publications
- Overview
- Year-wise publication list
  - Each item to follow this syntax: `Author names (Year) Title. Publication. DOI: XX.XXXX/XXXXXXXX.XXXX.XXXXXXX`
